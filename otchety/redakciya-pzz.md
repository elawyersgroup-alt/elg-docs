# Действующая редакция ПЗЗ: доля изменённых зон, маршрут через акт, консолидированный источник

**Дата:** 2 сентября 2026. **Исходные данные:** `egrn/moscow_zones_egrn.json` (387 зон из реестра границ, у 187 — реквизиты акта), книги 120-ПП с mos.ru (редакция апреля 2017), тексты постановлений с mos.ru.
**Статус:** все три задачи закрыты. Не до конца проверен один кандидат — ГИСОГД РФ (gisogd.gov.ru): портал отвечает из-за рубежа одной страницей за 46 секунд, остальные рукопожатия рвутся; в окне без VPN до него зонд не дошёл, VPN восстановился раньше.

## Строка вывода

**Рабочего маршрута к действующим параметрам для изменённых зон нет — ни через акт, ни через консолидированный источник.** Реквизит акта в ЕГРН может не разрешаться (участок 1); найденный акт (участок 2) содержит приложение в виде растрового фрагмента листа без координат и без чисел — для «Ф»-зон параметров не бывает, для остальных их снова придётся читать глазами и привязывать к листу вручную. Открытого источника действующей редакции целиком или карты с параметрами по подзоне в московском контуре нет; mka.mos.ru и isogd.mos.ru из открытой сети не отвечают, gradplan.mos.ru — мёртвый домен.

## 2. Маршрут «акт из ЕГРН → постановление на mos.ru → запись» — проверка на эталоне

### Как устроены постановления об изменениях на mos.ru

- Страница документа отдаёт **один файл — `.sig`**, открепленную подпись формата CMS в base64. Самого PDF по ссылке нет, но он **вложен внутрь подписи**; извлекается разбором ASN.1 (скрипт `scripts/cms_extract.py`). `openssl cms` не справляется: подпись ГОСТ.
- Извлечённые PDF имеют текстовый слой (11–15 шрифтов, 2–7 страниц). Текст постановления описывает изменение так: «карту … раздела 1 книги N … дополнить изображением территориальной зоны согласно приложению 1». Приложения 1 и 2 — **растровые фрагменты листа** (изображение 1444×1996 пикселей на страницу, около 30 КБ) с кодом квадрата, контуром зоны и подписью: код ВРИ на приложении 1, столбик или «Ф» на приложении 2. Код квадрата — часть картинки, в текстовом слое его нет. Адресов, кадастровых номеров и координат в актах нет.

### Участок 1 — ул. Брусилова, 33А (зона `77:06-7.4069`)

Реквизит из ЕГРН: № 2325-ПП от 15.10.2024. **На mos.ru такого документа нет.** 15 октября 2024 вышло 2315-ПП (по 819-ПП) и распоряжения об изъятии; изменения 120-ПП того периода — серия 2330–2352-ПП от 17.10.2024 (18 актов, все скачаны, ни один не касается Книги 8 и Южного Бутова). Существующие 2325-ПП: от 23.09.2025 (Книга 3, САО), от 25.10.2022 и от 23.12.2020 — не о нашей зоне. Дата регистрации границы в ЕГРН (07.08.2023) предшествует дате акта — реквизит внутренне противоречив.

Итог: маршрут обрывается на первом шаге. Действующие ВРИ и плотность 14 подтверждаются только условиями лота, не актом.

Время: 14 минут на поиск и проверку 22 актов, результат отрицательный.

### Участок 2 — ул. Михельсона, 56/2 (зона `77:03-7.6059`)

Реквизит из ЕГРН: № 3097-ПП от 10.12.2025 — **найден**: `doc/57070220`, PDF извлечён из подписи, 4 страницы, текстовый слой есть. Акт вносит изменения в Книгу 5 (ВАО): приложение 1 — фрагмент квадрата **J6-5-2-2** с новой зоной и кодом ВРИ **2.1**, приложение 2 — тот же фрагмент с обозначением **Ф Ф Ф**.

Что это значит. Акт не меняет параметры села Косино (столбик 5 / 15 / – на листе 2017 года), а вырезает из него одну новую зону сохраняемого землепользования под ИЖС. Зона ЕГРН `77:03-7.6059` ссылается на этот акт как на последний, её затронувший. Наш участок по чтению листа лежит в квадратах J6-5-2-3/J6-5-2-4, новая зона нарисована в J6-5-2-2 — [Likely] это соседний участок, не наш. Чисел в приложении нет: для «Ф» их и не бывает.

Время от реквизитов до приложения: **16 минут** первый раз (поиск через API mos.ru, извлечение PDF из подписи, рендер), повторно — около 3 минут. Чисел на выходе нет.

## 3. Консолидированный источник

**Открытого источника действующей редакции ПЗЗ целиком или публичной карты с параметрами по подзоне не найдено.** Проверено два прохода: при включённом VPN и в окне без VPN (00:16, 3 сентября).

| Источник | Что есть | Вывод |
| --- | --- | --- |
| mos.ru, страница 120-ПП (`doc/36260220`) | книги редакции апреля 2017 + текст постановления | действующей редакции нет |
| mos.ru, постановления об изменениях | текст акта + растровые фрагменты листов в приложениях; PDF вложен в `.sig` | это и есть «действующая редакция» — россыпью, сотни актов, без адресной привязки |
| mos.ru, раздел Москомархитектуры (`/mka/…`) | оболочка «Органы власти», ссылок на ПЗЗ, ИАИС или карту нет | пусто |
| stroi.mos.ru | раздел «ИСОГД» для специалистов — правила приёмки исполнительной документации в Сводный план; разделы `/structure/mka` — 404 | ИСОГД здесь — приём документов, не выдача |
| mka.mos.ru, isogd.mos.ru | не отвечают ни из-за рубежа, ни из окна без VPN (таймауты, пустой DOM в Chrome) | недоступны как публичные ресурсы |
| gradplan.mos.ru | имя указывает на чужой хост (сертификат `my-river.ru`) | мёртвый домен |
| data.mos.ru (открытые данные) | портал отвечает, поиск «ПЗЗ» — приложение на JS, наборов в статике нет | набора «территориальные зоны с параметрами» не обнаружено |
| ГИСОГД РФ, gisogd.gov.ru («Стройкомплекс.РФ») | портал с «Реестром документов»; из-за рубежа одна страница за 46 с, рукопожатия рвутся | единственный кандидат, не проверен до конца — см. ниже |
| НСПД, слой «Территориальные зоны» | границы и реквизиты акта; параметров нет (см. отчёт) | не источник параметров |

Про «Карту градостроительного зонирования» с плотностью, высотой и процентом по подзоне: упоминания относятся к листам книг ПЗЗ (раздел 1 каждой книги), где эти три числа и стоят столбиком, — то есть к тем самым растровым картам, а не к отдельному публичному сервису. Публичного веб-сервиса с этими числами по клику в проверенных источниках нет [Certain для проверенного; Likely для Москвы в целом].

ИАИС ОГД Москвы — система с доступом по учётным записям для органов власти и застройщиков; из открытой сети не отвечает. Если у практики есть доступ через ЕСИА или как у кадастрового инженера — это следующий кандидат, проверять нужно из-под учётной записи.

## 4. Что из этого следует

1. **Действующая редакция существует только как база 2017 года плюс несколько сотен постановлений об изменениях**, каждое с растровыми фрагментами листов. Собрать из этого актуальную карту машинно нельзя: фрагменты без координат, код квадрата — картинка.
2. **Для справки по конкретному участку** рабочий порядок такой: НСПД даёт зону и реквизит акта → если акт базовый (6% случаев) — запись из корпуса 2017 года; если акт об изменениях — найти его на mos.ru по номеру и дате, вытащить PDF из подписи, прочитать приложение глазами и привязать фрагмент к листу. Это 15–20 минут при удачном реквизите и тупик при битом (участок 1).
3. **Правило версионности из ТЗ v3.2** выполнимо в части признака: дата акта из ЕГРН позже 14.04.2017 — запись корпуса не применять. В части получения актуальных чисел оно упирается в ручное чтение приложений.
4. Открытый вопрос — ГИСОГД РФ и ИАИС ОГД под учётной записью.

## Техническое

Зона по участку — пересечением полигонов, не запросом по точке: на участке 3 запрос по точке вернул соседнюю зону. Реализация: полигон участка из ЕГРН и полигоны зон из GetFeatureInfo с расширенным окном, выбор той, чья площадь пересечения с участком максимальна.
