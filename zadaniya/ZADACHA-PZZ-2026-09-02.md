## 2. Первая и главная проверка: есть ли текстовый слой

Это единственный вопрос, ответ на который меняет стоимость проекта в разы. Делать до всего остального.

```bash
cd pzz/raw
for f in PZZ_*.pdf; do echo "=== $f ==="; pdfinfo "$f" | head -20; pdffonts "$f" | head -20; done
```

- **Шрифты перечислены** → текстовый слой есть. Числа со столбиков извлекаются координатно через `pdftotext -bbox-layout` или PyMuPDF, распознавание не нужно, стоимость актива падает на порядок. Немедленно сообщить Игорю: это меняет весь бюджет.
- **Пустая таблица шрифтов** → растр подтверждён окончательно, идти дальше по пунктам 3–5.

Дополнительная проверка руками, десять секунд: открыть книгу и попробовать выделить мышью числа на карте. Выделяются — слой есть.

## 3. Разметить структуру книг

Внутри каждого файла лежит несколько книг, внутри книги — разделы. Нужна карта: какие страницы это карты градозонирования (раздел 1), какие — текстовые регламенты по красным зонам (раздел 2), какие — по синим (раздел 3), какие — реквизиты актов по ЗОУИТ и ОКН (раздел 4).

```bash
# размер и тип содержимого постранично
python3 - <<'PY'
import pymupdf, json
for n in [2,3,4,5,6]:
    d = pymupdf.open(f"PZZ_{n}.pdf")
    rows=[]
    for i,p in enumerate(d):
        rows.append({"page":i+1,"w":round(p.rect.width),"h":round(p.rect.height),
                     "images":len(p.get_images()),"chars":len(p.get_text().strip())})
    json.dump(rows, open(f"../out/pages_PZZ_{n}.json","w"))
    print(n, len(rows), "страниц")
PY
```

Страницы с большим `chars` — текстовые. Страницы с нулевым `chars` и картинками — карты. Ландшафтная ориентация и крупный формат — тоже признак карты.

## 4. Текстовые разделы 2 и 3 — распознать и распарсить

Это дешёвая и полезная часть базы: регламенты зон с красной и синей маркировкой заданы текстом, а не подписью на чертеже.

```bash
# рендер текстовых страниц в 300 dpi и распознавание
pdftoppm -r 300 -f <первая> -l <последняя> -png PZZ_3.pdf ../out/txt_page
for i in ../out/txt_page-*.png; do
  tesseract "$i" "${i%.png}" -l rus --psm 6
done
```

Из распознанного вытащить структуру: номер подзоны, коды видов разрешённого использования, три числовых параметра, реквизиты акта. Складывать в CSV со столбцами:

```
zone_plot_id, okrug, rayon, density_ths_sqm_per_ha, height_limit_m,
built_up_ratio_pct, param_status, permitted_use_codes, source_book,
source_section, source_page, ocr_confidence
```

`param_status` — одно из `SET`, `NOT_ESTABLISHED`, `UNKNOWN`. **Прочерк в источнике — это `NOT_ESTABLISHED`, а не ноль.** Смешение этих состояний даёт завышенный резерв там, где ограничения нет, и заниженный там, где число не распозналось. Это критично: на этом ломается весь расчёт.

Отдельным файлом — список страниц, где распознавание дало низкую уверенность или противоречие.

## 5. Карты — оценить, читаемы ли числовые столбики

Не пытаться распознать всё. Задача — измерить, возможно ли это в принципе и с какой точностью.

```bash
# взять 5 страниц карт из разных книг, отрендерить в 600 dpi
pdftoppm -r 600 -f <N> -l <N> -png PZZ_2.pdf ../out/map_sample
```

Дальше: вырезать 20 фрагментов со столбиками, распознать их `tesseract --psm 7 -c tessedit_char_whitelist=0123456789.,-`, сверить с тем, что видно глазом. Посчитать долю верно прочитанных троек.

**Порог решения.** Точность выше 95% — числа берутся машинно, с выборочной сверкой. От 70 до 95% — машинно с обязательной сплошной сверкой человеком, что почти обесценивает автоматизацию. Ниже 70% — распознавание не применяется, три числа вводит человек глазами за пять минут на подзону, и это закладывается в себестоимость аудита.

## 7. Чего не делать

- Не строить базу по всей Москве. 32 тысячи подзон в лоб не нужны и не окупаются: наполнение идёт по мере продажи объектов, см. раздел 5 файла `ELG-TZ-v3-0-gradprofil.md`.
- Не трогать зоны с индексом «Ф» — их регламент вычисляется из ЕГРН, а не из ПЗЗ.
- Не заниматься Московской областью.
- Не изобретать значения. Если параметр не распознался — статус `UNKNOWN`, и он обязан снижать итоговую оценку, а не подставляться нулём.
- Не публиковать и никуда не выкладывать содержимое книг: это нормативный акт, но объём выгрузки — отдельный вопрос, который решает Игорь.

Проверить, что фактически лежит в реестре границ ЕГРН по московским территориальным зонам. Если поле заполнено параметрами, значительная часть работы по книгам вообще не нужна. Проверяется по любому кадастровому плану территории в XML из практики Игоря либо через НСПД при выключенном VPN.
