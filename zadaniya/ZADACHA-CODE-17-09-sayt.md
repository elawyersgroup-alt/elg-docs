## Задача 47 — репозиторий `elg-site`

**Публичный.** Сайт и так отдаётся всем в интернете, HTML-исходники секретом не являются; а Claude в чате читает только публичные репозитории, и вёрстка без исходников невозможна. Исключить из репозитория всё, что не отдаётся браузеру: `.htaccess` с чем-либо кроме редиректов, конфиги хостинга, любые файлы с паролями и ключами. Проверить каждый файл перед первым пушем.

1. Игорь создаёт `elg-site` на GitHub, публичный, даёт тебе запись.
2. Выгрузить с Hostland весь каталог сайта как есть: 54 HTML, CSS, JS, изображения, `sitemap.xml`, `robots.txt`, `favicon`. Способ — FTP или архив через панель; если доступа нет — Игорь скачивает архив в панели Hostland и передаёт тебе.
3. `README.md`: структура, где общий CSS, как устроены меню и подвал (вставлены в каждый файл или подключаются), какие страницы — шаблоны для новых. Отдельно перечислить фрагменты, которые повторяются на всех страницах дословно, — их придётся править во всех 54 файлах, и это делаешь ты скриптом, не руками.
4. Правило в README: источник истины — репозиторий; на Hostland уходит только закоммиченное; правок на сервере мимо git больше нет.

## Задача 48 — оферта на Градпрофиль

По образцу оферты на проверку: предмет — справка о градостроительном режиме участка по открытым и официальным источникам на дату; Г2 за 1 рабочий день и Г3 за 7 рабочих дней с отдельным разделом о сведениях ИАИС ОГД (срок органа, плата перевыставляется, ответ органа не гарантируется по составу); явно: параметры со статусом «ориентировочно» — не основание для проектных решений; возврат до направления справки; зачёт Г1а/Г1б. Реквизиты, налоговый режим, часы — подстановки в квадратных скобках. Статус ПРОЕКТ, в `elg-docs/teksty/`.

## Задача 49 — подготовка образцов для страниц

Для страниц нужны фрагменты отчёта и справки на синтетическом номере 77:99:0000000:1 с водяным знаком: три PNG для проверки (первая строка со светофором, таблица «что проверено», блок «что не проверено») и три PNG для справки (шапка с разделом 1, таблица зоны с источником, раздел 12).
