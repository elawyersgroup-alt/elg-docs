# Задание Claude Code — 04.09.2026. Окно ожидания: собрать сам продукт

**Контекст.** Запрос в ИАИС ОГД подаётся в понедельник 07.09, ответ по регламенту — 5 рабочих дней, то есть около 12–15 сентября. Это окно в неделю. Тратить его на источники ПЗЗ больше нельзя: за четыре дня закрыто тринадцать задач по одной строке справки — предельным параметрам, — и ноль по остальным. Клиент платит 25 000 ₽ прежде всего за ответ «что мешает», а не за «какая плотность».

Порядок на окно: 10 → 14 → 15 → 16 → 17, затем 11–13.

---

## Задача 10 — код квадрата из текстового слоя (без изменений, дёшево, делать первой)

Извлечь коды квадрата из текстового слоя всех 6 795 PDF, записать в `acts_index.csv` с полем `kvadrat_source` = `TEXT` / `OCR`, для `TEXT` ставить `ocr_confidence = 1.0`, посчитать покрытие по годам. Распознавание при этом не трогать.

## Задача 14 — сборщик профиля объекта, приоритет первый после 10

Это шаг 1 конвейера из ТЗ, и он до сих пор не построен. Вход — кадастровый номер участка. Выход — структурированный JSON.

Собрать по каждому участку:

1. **Участок из ЕГРН:** площадь, категория земель, ВРИ по реестру, адрес, полигон границ, статус записи, обременения и ограничения из выписки.
2. **Здания и сооружения на участке:** кадастровые номера, площадь, этажность, год, назначение, статус.
3. **Территориальная зона ПЗЗ:** определять **пересечением полигонов**, не запросом по точке. Полигон участка из ЕГРН, полигоны зон из `GetFeatureInfo` с расширенным окном, выбирается зона с максимальной площадью пересечения. Правило сформулировано ещё в отчёте от 02.09 и до сих пор не реализовано — на участке 3 запрос по точке дал соседнюю зону.
4. **ЗОУИТ**, пересекающие участок: вид, реестровый номер, реквизиты решения, доля площади участка в зоне.
5. **Объекты культурного наследия** и их защитные и охранные зоны.
6. **КРТ**, проекты планировки, изъятие для государственных нужд.
7. **Красные линии** и приаэродромные территории, если слой доступен.

По каждому пункту — поле `source` и `retrieved_at`. Отсутствие данных пишется как `UNKNOWN`, не как «нет ограничений»: это разные вещи, и вторая продаёт клиенту неверный вывод.

Ресурсы Росреестра и НСПД открываются только в окне с выключенным VPN — планировать заходы пачками.

## Задача 15 — шаблон справки и верификатор

1. Шаблон документа справки по разделу 02 ТЗ: разделы, порядок, обязательные оговорки, дисклеймер «не является юридической консультацией».
2. Каждое числовое значение выводится с `source_tier` (`GPZU` / `ISOGD` / `ACT_MANUAL` / `CORPUS_2017`).
3. **Верификатор блокирует выпуск**, если вывод о возможности строительства опирается на значение уровня `CORPUS_2017` без пометки «редакция апреля 2017 года, ориентировочно». Это не рекомендация, а проверка, которая не даёт собрать файл.
4. Вторая проверка: если поле помечено `UNKNOWN`, оно должно попасть в раздел «что не удалось установить», а не исчезнуть из документа.

## Задача 16 — пилот на трёх отработанных участках

Собрать три полные справки: Брусилова 33А, Михельсона 56/2, Колокольников 15. Строку предельных параметров оставить пустой с пометкой «ожидается ответ ИАИС ОГД» — она заполнится, когда придёт ответ.

**Замерить и сдать отдельной таблицей:** время на каждый шаг конвейера по каждому участку, сколько шагов потребовало ручной работы, сколько полей осталось `UNKNOWN`. Это норматив себестоимости, от которого зависит, держится ли цена 25 000 ₽ и сколько справок в день вообще возможно.
