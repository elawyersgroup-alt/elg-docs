## 2. Сервер — выбор и цена

**Выбор: Timeweb Cloud, Москва, MSK 50** — 2 ядра 3,3 ГГц, 4 ГБ памяти, 50 ГБ NVMe, канал 1 Гбит/с, публичный IP. Цена — 1 200 ₽/мес без скидки; скидки за предоплату: 3 мес — 5 %, 6 мес — 7 %, 12 мес — 10 %. Оплата почасовая, сервер можно увеличить без переустановки.
Источник: timeweb.cloud/services/cloud-servers (Москва, «1 мес без скидки», 26.09.2026): MSK 40 — 1 000 ₽ (2 ядра, 2 ГБ, 40 ГБ), MSK 50 — 1 200 ₽, MSK 80 — 2 000 ₽ (4 ядра, 8 ГБ, 80 ГБ). Автобэкапы — timeweb.cloud/prices: 6 ₽/мес за 1 ГБ.

**Почему 4 ГБ, а не 2:** распознавание уведомлений (Tesseract) на многостраничных PDF и еженедельные проверки по реестру границ идут параллельно; 2 ГБ — впритык. Начинаем с MSK 50, при росте — MSK 80 без переезда.

**Сравнение:** Selectel, Standard Line — «от 948,50 ₽/мес» за минимальную конфигурацию (selectel.ru/services/cloud/servers, 26.09.2026); диск и адрес считаются отдельно — сопоставимая конфигурация выходит не дешевле. Yandex Cloud — поресурсная оплата, дороже для постоянно работающего сервера [Likely — не считал].

**152-ФЗ:** сервер и база — в Москве, персональные данные граждан хранятся в России. Hostland (сайт) остаётся как есть; приложение — отдельный сервер.

## 3. Как устроено приложение

- **Адрес:** app.argument-law.ru — веб-приложение (PWA): ставится на телефон из браузера значком, работает как приложение. Основной сайт остаётся на Hostland; с сайта — ссылки «Мои объекты», «Прислать уведомление».
- **Стек:** Python 3.12 + FastAPI, база SQLite (WAL, ежедневная копия), страницы — HTML/CSS/JS в дизайне сайта без сборщиков; service worker и manifest для установки. Почему Python: проверки, паспорт и справки уже написаны на Python (НСПД, ГАР, индекс актов, реестр границ, ВРИ) — переносятся, а не пишутся заново.
- **Вход без пароля:** одноразовая ссылка на почту (живёт 15 минут, одно использование), сессия 30 дней. Внутри MAX — вход по подписи данных запуска (HMAC-SHA256 с токеном бота, dev.max.ru/docs/webapps/validation) — без почты.
- **Удаление аккаунта и данных** по кнопке — требование правил MAX (п. 4.5.5) и 152-ФЗ.
- **Кабинет юриста** (Игорь): список «ждёт вас», черновик, «отправить». До готовности кабинета — письмо Игорю с черновиком.
- **Проверки по реестру границ** переезжают на сервер (российский адрес — без прокси; корневой сертификат Минцифры — в хранилище сервера).
- **Уведомления Игорю** (п. 3.5 пакета): почта сразу; push в кабинете юриста; MAX — сообщением бота, когда бот появится. Тихие часы 21:00–9:00 — только сбои и сроки приостановки, остальное сводкой в 9:00.

## 5. MAX — мини-приложение возможно (доклад по п. 3.3)

- Мини-приложения — веб-страницы (HTML, JS, CSS), которые открываются внутри MAX; **работают только внутри чат-бота** организации (dev.max.ru/docs/webapps/introduction).
- Подключение доступно юрлицам, ИП и самозанятым — резидентам РФ. Нужны профиль на платформе MAX для партнёров (business.max.ru) с верификацией, лицензионный договор с ООО «MAX» и бот, который проходит модерацию. Мини-приложение подключается в настройках бота ссылкой https.
- Ссылка на запуск: max.ru/<имя бота>?startapp=<параметр> — можно вести из писем и с сайта прямо в приложение.
- Наше PWA подходит без переделки: подключаем библиотеку MAX Bridge и вход по данным запуска.
- Правила площадки (ред. от 11.06.26, dev.max.ru/docs/legal/rules): разработчик — самостоятельный оператор персональных данных; публикует документы об обработке данных и обеспечивает их принятие; даёт удалить аккаунт; MAX вправе ограничить приложение без объяснения причин.

## 6. ЮKassa — автоплатежи (доклад по модулю 5)

- По умолчанию автоплатежи работают только в тестовом магазине; для боевого — **написать менеджеру ЮKassa** и дождаться настройки магазина (yookassa.ru/developers/…/recurring-payments/basics).
- Порядок: оферта с условиями подключения и отключения автоплатежей → письмо менеджеру → настройка магазина → на нашей стороне: информирование, периодичность и сумма, отключение.
- Способ оплаты сохраняется при первом платеже (с согласия пользователя на форме) или привязкой на нулевую сумму; отключение — только на нашей стороне (перестаём создавать платежи), пользователь может отозвать разрешение через банк.
- До подключения: «Собственник» — годовой платёж по ссылке; «Бизнес» — счёт на год или квартал (PRICE.md).
