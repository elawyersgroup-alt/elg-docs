# elg-docs — документы проекта ELG Градпрофиль

Публичный репозиторий с правилами, ТЗ, ценами, заданиями и отчётами проекта ELG Градпрофиль (ИП Еланский И. Ю., ELAWYERS GROUP): платные градостроительные справки и проверка на изъятие и КРТ по Москве как вход в юридическую практику.

**Источник истины — этот репозиторий. Флешка SANDISK — копия на дату.** Скрипты, индексы, профили участков, справки, выписки и конфиги лежат в приватном репозитории `elg-pzz`; сюда они не попадают, как и любые клиентские данные.

## Как читать

1. `CLAUDE.md` — правила работы Claude Code: роли, канон, замеры, синтетика, документ, отчёт.
2. `PRICE.md` — единственный источник цен и SKU. Все остальные документы на него ссылаются.
3. `DOCS.md` — реестр документов: что действует, что чем заменено, чего нет.
4. Дальше по папкам: `tz/` (ТЗ, старые версии в `tz/archive/`), `kanon/`, `zadaniya/` (задания Claude Code), `otchety/` (отчёты, сводки, сборники), `status/` (статус фирмы и сайта), `teksty/` (тексты продаж, оферты).

## Как это использует Claude в чате

В начале каждого разговора Claude в чате клонирует репозиторий и читает `CLAUDE.md`, `PRICE.md`, `DOCS.md` и последнее задание в `zadaniya/`:

```bash
git clone https://github.com/<владелец>/elg-docs.git
```

С этого момента отчёты Claude Code в чат не носятся: они коммитятся в `otchety/` в день сдачи, а Claude в чате читает их из репозитория.

## Как сдаётся работа

- Отчёт по заданию — файл в `otchety/` с датой в имени, коммит в тот же день. Первая строка — вывод, неудобное первым, у каждого вывода [Certain] / [Likely] / [Speculation].
- Новое задание — файл в `zadaniya/` с датой в имени.
- Изменение цены или ТЗ — только Игорь, правкой `PRICE.md` или новой версией ТЗ в `tz/` с записью в `DOCS.md`.
