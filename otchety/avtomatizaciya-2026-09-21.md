## 2. Исполнитель заказов — как устроен и как проверен

`elg-pzz/scripts/zakaz_worker.py`. Очередь ведёт сторож (`site_watch.py`): новый заказ — в `orders_queue.json`, и на каждой удачной проверке сайта сторож будит исполнителя, поэтому заказ, ждавший российского IP, подхватится сам. Сборка идёт отдельным процессом и от двух запусков сразу защищена замком.

Номер приходит из веб-формы, то есть от кого угодно. В командную строку он попадает только после проверки по шаблону `NN:NN:NNNNNN(N):N…` и только списком аргументов, без оболочки.

Проверено 21.09:

| Проверка | Результат |
| --- | --- |
| Сборка по пилотному участку без сети (готовый профиль) | 5 секунд, итог 🟡, PDF на месте, сопроводительный текст и строка учёта записаны, окно «Отчёт готов» показано |
| Нет российского IP | состояние «ждёт российского IP», окно один раз; на втором проходе — молча |
| Адрес вместо номера | «нужны руки», со ссылкой на пункт RUNBOOK |
| Участок не в Москве | «нужны руки», со ссылкой на оферту |
| Вместо номера — `77:01:0001001:1; rm -rf ~` | отброшено как «не кадастровый номер», до командной строки не дошло |
| Сторож после доработки | работает, код выхода 0 |

**Не проверено:** живой сбор профиля с НСПД через исполнителя (`--live`) — в этой сессии российского IP не было ни разу. Сама команда та же, что в RUNBOOK; первый настоящий прогон покажет, укладывается ли она в отведённые исполнителем 25 минут.

Команды: `zakaz_worker.py status` — что в очереди; `retry <номер>` — вернуть заказ в работу после сбоя.

## 3. Письмо клиенту после заказа — написано, не выложено

**Что это.** Сразу после заказа человеку уходит письмо: «Номер принят. Ссылка на оплату ниже — после оплаты отчёт придёт в течение часа в рабочее время, по рабочим дням с 10:00 до 19:00», ссылка ЮKassa, строка про VPN, фраза про выписку ЕГРН. Это буквально п. 3 оферты: ссылку направляет Исполнитель после получения номера. Текст собран из фраз, которые Игорь уже утвердил для бота 20–21.09; для Г2 срок — «в течение рабочего дня».

**Как защищено от превращения формы в рассыльщик.** В письмо не попадает ни слова, набранного посетителем, кроме кадастрового номера строгого вида. Не больше одного письма на адрес за 12 часов и десяти в час на всех. В журнале лимитов — отпечаток адреса, не адрес. Рассылка выключена, пока на сервере нет файла-выключателя; образец уходит только на info@el-group.com.ru — получатель зашит в код.

**Почему не работает.** При выкладке защитный фильтр среды отказал: автоматические письма третьим лицам со ссылкой на оплату. Code отказ принял и обходить не стал. Код лежит в ветке `pismo-klientu` репозитория `elg-pzz`; основная ветка по-прежнему совпадает с сервером по SHA-256.

## 4. Бот и почта: что автоматизировать можно, а что нельзя

**Бот @elawyers_bot** уже отвечает сам там, где ответ однозначен: принимает номер, отдаёт ссылки на оплату и строку про VPN. Добавить можно ответы на четыре повторяющихся вопроса — «сколько стоит», «какой срок», «что входит в проверку», «участок не в Москве». Тексты для них есть на страницах продуктов, утверждённых Игорем; Code соберёт блок из этих формулировок и вставит в PuzzleBot **по слову Игоря** — это публикация подписчикам.

**Общий автоответчик на ящике info@el-group.com.ru Code не предлагает.** Ящик рабочий: автоответ получат суды, контрагенты и рассылки. Точечный ответ клиенту делает письмо из раздела 3.

**Свободные ответы клиентам «от имени юриста» автоматизировать нельзя** — ни в боте, ни в почте. Это юридическая консультация; канон запрещает додумывать, а отвечает за сказанное Игорь.

**Что ещё можно, но не сделано:**

- **Сверка оплаты.** ЮKassa шлёт письмо о платеже на ящик Игоря. Разбирать эти письма автоматически — значит дать скрипту читать рабочий ящик; это отдельное решение Игоря.
- **Российский IP без рук.** Сборку можно перенести с Мака на сервер в России (не виртуальный хостинг — там PHP 7.0 и нет нужного окружения, а небольшой VPS). Тогда VPN на Маке перестанет влиять на срок. Это расход и отдельный проект.
- **Уведомления в Telegram на телефон.** Сторож умеет; нужен файл с токеном бота, который заводит Игорь.
